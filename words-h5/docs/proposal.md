## 1. 项目概述

### 1.1 背景

基于现有的 Next.js 脚手架（已内置邮箱密码登录 / 注册能力），构建一个移动端 H5 英语单词学习应用。用户可以在手机浏览器中选择单词书、以卡片形式背单词，并保存学习进度。

### 1.2 项目目标

- 提供单词书浏览、单词学习（卡片）、单词详情查看的完整闭环。
- 用户登录后自动记录学习进度，可从上次学习的位置继续学习。
- 移动端优先的 UI 体验，底部 Tab 导航。

### 1.3 技术栈（沿用现有脚手架）

| 层级 | 技术 |
| --- | --- |
| 前端框架 | Next.js 14（App Router）+ React 18 + TypeScript |
| 样式 | Tailwind CSS（移动端 H5 优先适配） |
| 认证 | NextAuth v5（Credentials：邮箱 + 密码） |
| 数据库 | PostgreSQL + Drizzle ORM |
| 密码加密 | bcrypt-ts |

## 2. 页面结构与导航

整体采用 **底部双 Tab 布局**：`首页` 与 `我的`。

| Tab | 路由 | 说明 |
| --- | --- | --- |
| 首页 | `/` | 单词书列表 + 最近学习 |
| 我的 | `/mine` | 用户信息、学习进度、退出登录 |

学习相关页面（不显示底部 Tab 或按需保留，建议不保留以获得沉浸式体验）：

| 页面 | 路由 | 说明 |
| --- | --- | --- |
| 单词书详情（单词列表） | `/book/[bookId]` | 展示该书全部单词 |
| 单词学习（卡片） | `/study/[bookId]` | 卡片式学习，切换单词 |
| 单词详情 | `/word/[wordId]` | 单词完整数据渲染 |

## 3. 功能需求详述

### 3.1 首页（Tab 1）

**FR-1 已登录状态：**

- 顶部展示【最近学习】模块：显示用户最近学习的一本单词书（书名 + 进度，如 `12/48`），点击后进入该书的单词学习页，并从**上次学习的下一个单词**开始继续。
- 【最近学习】无数据（从未学习过任何书）时，整个模块**不渲染**。
- 【最近学习】下方展示【全部单词书】列表，点击任一单词书进入该书详情页（单词列表）。

**FR-2 未登录状态：**

- 只展示【全部单词书】列表，**不展示**【最近学习】。
- 用户点击单词书时，不进入详情页，而是**跳转到【我的】页面并自动弹出登录 popup**（popup 内支持登录与注册切换）。
- 登录成功后回到原流程（继续打开用户刚才点击的单词书）。

### 3.2 我的（Tab 2）

**FR-3 已登录状态：**

- 展示用户邮箱。
- 展示学习进度列表：用户学习过的每本单词书的进度（如 `PEP三年级上册 12/48`），点击可继续学习。
- 提供【退出登录】按钮，退出后回到未登录状态的【我的】页面。

**FR-4 未登录状态：**

- 展示引导文案与【登录 / 注册】按钮，点击弹出登录 popup。

### 3.3 登录 / 注册 popup

**FR-5：**

- 以 popup（底部抽屉或居中弹窗）形式呈现，包含两个可切换的 Tab：`登录` / `注册`。
- 登录：输入邮箱 + 密码，调用现有 `signIn('credentials')` 逻辑（参考 `app/login/page.tsx`）。
- 注册：输入邮箱 + 密码，调用现有 `createUser / getUser` 逻辑（参考 `app/register/page.tsx`），注册成功后自动登录。
- 登录 / 注册成功后关闭 popup，并执行登录前的上下文动作（如打开刚点击的单词书）。
- 简易校验：邮箱格式校验、密码非空；失败时展示错误提示。

### 3.4 单词书详情（单词列表）

**FR-6：**

- 顶部展示单词书名称。
- 列表展示该书所有单词：`序号 + 单词 + 中文释义（取 trans[0].tranCn，仅一条）`。
- 每个单词可点击，进入该单词的详情页。
- 页面提供【开始学习 / 继续学习】按钮，进入卡片学习页。

### 3.5 单词学习（卡片页）

**FR-7：**

- 进入页面时定位到**该用户在该书最近学习的单词的下一个**；若从未学习，则从第 1 个单词开始。
- 以**单词卡片**形式展示，卡片尽量简单，只渲染：
  - 单词（headWord）
  - 音标（usphone / ukphone，择一展示，优先美式）
  - 一条中文释义（`trans[0].tranCn`）
  - **一条示例**（优先 `sentence.sentences[0]` 的 `sContent + sCn`；无例句时降级为 `phrase.phrases[0]`，再无则不展示）
- 底部提供【下一个】按钮，点击切换到下一个单词。
- 详细学习入口：**点击卡片本身**进入单词详情页，详情页可返回学习页。
- 每切换到一个新单词，实时更新该用户在该书的学习进度（记录 `wordRank`）。

### 3.6 单词详情页

**FR-8：**

- 渲染单词 JSON 中 `content.word.content` 的全部有效字段：

| 模块 | 数据来源 | 展示方式 |
| --- | --- | --- |
| 单词 + 音标（美/英） | `headWord`、`usphone`、`ukphone` | 顶部大标题 + 两行音标 |
| 释义 | `trans[].tranCn / tranOther` | 列表（中文释义 + 英文释义） |
| 例句 | `sentence.sentences[].sContent / sCn` | 列表 |
| 短语 | `phrase.phrases[].pContent / pCn` | 列表 |
| 同近义词 | `syno.synos[]`（按词性 `pos` 分组） | 分组标签 + 词条 |
| 同根词 | `relWord.rels[]`（按词性分组） | 分组标签 + 词条 |
| 记忆方法 | `remMethod.val` | 卡片 / 高亮块 |

- 字段缺失时对应模块不渲染。

## 5. 数据模型设计

### 5.1 现有表

`User`（已存在于 `app/db.ts`）：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | SERIAL PK | 用户 ID |
| email | VARCHAR(64) | 邮箱（唯一标识） |
| password | VARCHAR(64) | bcrypt 哈希 |

### 5.2 新增表

**Book（单词书）** — 数据源为 `words-admin/temp/*.json`（每文件一本，文件名即 `bookId`）：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| bookId | VARCHAR PK | 如 `PEPXiaoXue3_1` |
| name | VARCHAR | 单词书名称（如「PEP三年级上册」） |
| wordCount | INTEGER | 单词总数（导入时统计） |
| sort | INTEGER | 首页排序 |

**Word（单词）** — 对应 JSON 中一行记录：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| wordId | VARCHAR PK | 如 `PEPXiaoXue3_1_1` |
| bookId | VARCHAR FK | 所属单词书 |
| wordRank | INTEGER | 单词序号（学习顺序） |
| headWord | VARCHAR | 单词 |
| content | JSONB | 原样存储 `content.word.content` |

**StudyProgress（学习进度）**：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | SERIAL PK | |
| userId | INTEGER FK | 用户 ID |
| bookId | VARCHAR FK | 单词书 |
| lastWordRank | INTEGER | 最近学习的单词序号（wordRank） |
| updatedAt | TIMESTAMP | 最近学习时间（用于「最近学习」排序） |

唯一约束：`(userId, bookId)`。

### 5.3 单词 JSON 字段选用说明

源数据结构（`PEPXiaoXue3_1.json` 每行一个单词）：

```json
{
  "wordRank": 5,
  "headWord": "bag",
  "content": {
    "word": {
      "wordHead": "bag",
      "wordId": "PEPXiaoXue3_1_5",
      "content": {
        "sentence": { "sentences": [{ "sContent": "...", "sCn": "..." }] },
        "usphone": "bæɡ",
        "ukphone": "bæɡ",
        "trans": [{ "tranCn": "包", "tranOther": "a flexible container..." }],
        "phrase": { "phrases": [{ "pContent": "plastic bag", "pCn": "塑料袋" }] },
        "syno": { "synos": [{ "pos": "n", "tran": "袋", "hwds": [{ "w": "killing" }] }] },
        "relWord": { "rels": [{ "pos": "adj", "words": [{ "hwd": "baggy", "tran": "宽松的" }] }] },
        "remMethod": { "val": "记忆口诀..." }
      }
    }
  },
  "bookId": "PEPXiaoXue3_1"
}
```

- **列表页**：`headWord` + `trans[0].tranCn`
- **学习卡片**：`headWord` / `usphone` / `ukphone` / `trans[0].tranCn` / `sentence.sentences[0]`（降级 `phrase.phrases[0]`）
- **详情页**：`content.word.content` 全字段（见 3.6）
- 数据文件行尾无逗号、每行一个 JSON 对象，导入脚本按 NDJSON 逐行解析入库。

## 6. 关键业务流程

### 6.1 未登录用户点击单词书

```
首页点击单词书
   │
   ▼
未登录？ ──是──▶ 跳转【我的】+ 弹出登录 popup
   │                    │
   否                登录 / 注册成功
   │                    │
   ▼                    ▼
进入单词书详情页 ◀──── 自动打开刚才点击的单词书
```

### 6.2 学习进度推进

```
进入 /study/[bookId]
   │
   ▼
读取 StudyProgress(userId, bookId)
   │
   ├── 无记录 ──▶ 从 wordRank = 1 开始
   └── 有记录 ──▶ 从 lastWordRank + 1 开始（超出总词数则提示学完）
   │
   ▼
点击【下一个】──▶ 渲染下一张卡片
   │             └─▶ upsert StudyProgress(lastWordRank, updatedAt)
点击卡片 ─────▶ 进入 /word/[wordId] 详情页（可返回学习页）
```

### 6.3 首页「最近学习」

- 查询该用户 `StudyProgress` 中 `updatedAt` 最新的一条记录，关联 Book 展示；无记录则隐藏模块。

## 7. 接口设计（Server Actions / Route Handlers）

| 能力 | 方式 | 说明 |
| --- | --- | --- |
| 登录 | 沿用 `signIn('credentials')` | 参考 `app/login/page.tsx` |
| 注册 | 沿用 `createUser / getUser` | 参考 `app/register/page.tsx` |
| 获取单词书列表 | Server Component 直查 DB | 首页渲染 |
| 获取最近学习 | Server Component 直查 DB | 首页 / 我的 |
| 获取单词书单词列表 | Server Component 直查 DB | `/book/[bookId]` |
| 获取学习起始单词 | Server Action | `/study/[bookId]` 加载时 |
| 切换下一个 & 保存进度 | Server Action | `saveProgress(userId, bookId, wordRank)` |
| 获取单词详情 | Server Component 直查 DB | `/word/[wordId]` |
| 退出登录 | 沿用 `signOut()` | 【我的】页面 |

## 8. 非功能需求

| 项 | 要求 |
| --- | --- |
| 适配 | 移动端优先（375px 基准），桌面端居中限宽（如 max-w-md） |
| 性能 | 单词书列表首屏服务端渲染；详情页 JSONB 数据按 wordId 单条查询 |

| 兼容 | 现代移动端浏览器（iOS Safari / Android Chrome） |
| 数据导入 | 提供导入脚本将 `words-admin/temp/*.json` 批量导入 Book / Word 表 |

## 9. 验收标准（Acceptance Criteria）

1. 未登录时首页仅显示单词书列表；点击单词书跳转【我的】并弹出登录 popup，登录成功后自动打开该单词书。
2. 登录后首页显示【最近学习】（无记录时隐藏），点击可从上次位置的下一个单词继续学习。
3. 单词学习页为简单卡片（单词 / 音标 / 一条释义 / 一条示例），【下一个】可切换并持久化进度，点击卡片可进入详情页。
4. 单词详情页完整渲染释义、例句、短语、同近义词、同根词、记忆方法，缺失字段不渲染。
5. 【我的】页面显示邮箱、各书学习进度、退出登录；退出后恢复未登录态。
6. 底部始终有【首页】【我的】双 Tab，当前 Tab 高亮。
